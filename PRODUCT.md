# Family Finance
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Сергей и Светлана ведут общий семейный бюджет, в том числе с телефона.

## Product Purpose
Контроль месячного бюджета, остатков, операций и расходов. Пользователь подтвердил 27 октября 2026: бюджет месяца — приоритет первого экрана.

## Capabilities and Constraints
Сохранить экраны операций, фильтры, счета, планы и дашборды. Валюты RSD, EUR, RUB, USD не суммировать без конвертации. Доступ защищён собственными аккаунтами, регистрацией по приглашению и серверными сессиями; данные хранятся в Cloudflare D1 (SQLite). API только читает данные; изменение записей выполняется через SQL-инструменты Cloudflare. Автоматического импорта и демонстрационных финансовых записей нет.

## Brand Commitments
Family Finance / Семейные финансы. Русский интерфейс. Доработка знакомого тёмного рабочего кабинета, а не новый бренд.

## Evidence on Hand
Реальный API и существующие компоненты. Референсы: официальные продуктовые страницы YNAB, Monarch и Actual Budget. Функции референсов не обещать, если сайт их не реализует.
